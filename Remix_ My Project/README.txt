# README for Remix: My Project

This is a standalone website adapted from a Code.org App Lab export.

* `index.html` contains the app screens and loads the local JavaScript and CSS.
* `web-runtime.js` provides browser implementations of the App Lab functions used by this project.
* `code.js` contains the game logic.
* `style.css` and `applab/applab.css` provide the exported app styling.
* `assets` contains the images and sounds used by the app.

To run it locally, serve this folder with a static web server and open `index.html`.
Keep the files and folders together when publishing the site.
